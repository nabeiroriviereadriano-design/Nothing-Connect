# Installation

## Windows (10 22H2 ou plus récent, 64 bits)

1. Téléchargez `NOTHING CONNECT_x.y.z_x64-setup.exe` depuis la page Releases.
2. Double-cliquez. Si Windows SmartScreen affiche « Windows a protégé votre ordinateur » :
   **Informations complémentaires > Exécuter quand même** (l'installeur n'est pas encore signé
   par un certificat de code ; voir « Limites » dans la matrice des fonctions).
3. L'installation se fait pour votre compte uniquement, sans droit administrateur.
4. Au premier lancement, Windows demande l'accès réseau : cochez **Réseaux privés** et validez.
5. Votre réseau Wi-Fi doit être réglé en **réseau privé** dans Windows (Paramètres > Réseau et
   Internet > Wi-Fi > votre réseau > Profil réseau : Privé), sinon le téléphone ne trouvera pas le PC.

## Android (10 ou plus récent)

1. Sur le téléphone, téléchargez le fichier `.apk` depuis la page Releases.
2. Ouvrez-le ; autorisez l'installation depuis le navigateur si Android le demande.
3. Ouvrez NOTHING CONNECT, autorisez les notifications.

## Associer

1. PC : **Associer un téléphone** (Accueil ou Appareils). Un code et un QR code s'affichent.
2. Téléphone : **Scanner le QR code**, ou touchez le PC détecté puis tapez le code.
3. PC : vérifiez le nom du téléphone et cliquez **Autoriser**.
4. Téléphone : sur l'Accueil, autorisez l'accès aux notifications et retirez la restriction de
   batterie pour une connexion stable.

## Mettre à jour

- Windows : Paramètres > Mises à jour > Rechercher, puis Installer. Un bandeau s'affiche aussi
  au démarrage quand une version est disponible.
- Android : Réglages > Mises à jour > Rechercher, puis Installer.

Appareils associés, historique et réglages sont conservés.
